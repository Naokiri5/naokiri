# Fundamental intelligence

Status: implementation design for subsequent increments; not a claim of completion.

Current CoinGecko metadata is partial crypto context, not comprehensive fundamentals. Add sourced timestamped typed records per asset class and per-metric expiry. Store publication and available-at times for historical queries. Financial statements, central-bank events, tokenomics and inventories require appropriate sources. Acceptance: expired/future/wrong-asset metrics abstain; critical event uncertainty cannot silently pass risk checks.
