## Prioritized prerequisites

1. Preserve existing fresh-book fills, protection incidents, independent risk veto, paper/live separation and record provenance while implementing the small UI slice.
2. Use the existing six-group navigation/global Joe instead of creating duplicates. Add only genuinely missing density/monitor presentation and fix request ownership where needed for correct symbols/cohorts.
3. Before unattended claims: approved host/supervision, explicit readiness/loop heartbeat, tested restart/drain/single-instance deployment, automated consistent backup and a real restore drill.
4. Execute a genuine 24-hour all-viewers-closed paper-only soak; do not compress time or substitute mocks and then call it uptime certification.
5. Keep real funds, signing and withdrawals locked; additional providers/desktop packaging/external monitoring require separate owner setup and authorization.
