    ## 1. Repository Identity & Runtime Stack​
    - **Repository:** `https://github.com/Naokiri5/naokiri` (MIA 5.0)​
    - **Workspaces:** npm workspaces `@mia/server` (`./server`) and `@mia/web` (`./web`),
    deployed with Vite and Cloudflare Wrangler (`server/wrangler.jsonc`).​
    - **Runtime:** Node.js `22.23.5` with native TypeScript execution (`node path/to/file.ts`) and
    built-in `node:sqlite` (`DatabaseSync`).​
    - **Zero Native Addon Rule:** NEVER introduce `better-sqlite3`, `sqlite3`, or C++ node-gyp
    bindings. Always use Node 22's built-in `node:sqlite`.​
    - **Testing Framework:** Vitest (`npx vitest run`).​
    ​
    ## 2. Hard Safety, Execution & Capital Invariants​
    1. **Default Paper Lock:** All five portfolio sleeves (`futures`, `spot`, `memecoin`, `yield`,
    `stocks_etf`) initialize and operate in `PAPER` shadow mode
    (`MIA_EXECUTION_MODE=PAPER`, `ALLOW_LIVE_TRADING=false`) by default.​
    2. **30-Trade Rolling Expectancy Promotion Gate:** No sleeve may transition from `PAPER`
    to `LIVE` unless `UnifiedRiskGovernor` verifies ALL THREE conditions over the most recent

`30` (`min_trades_required`) `FILLED` trades in `ledger_orders`:​
  - `rolling_trade_count >= 30`​
 - `rolling_expectancy_r >= sleeve.min_expectancy_r`​
 - `rolling_max_drawdown_pct <= sleeve.max_daily_drawdown_pct`​
3. **Automatic Decay Revocation & Drawdown Halt:**​
 - If a `LIVE` sleeve's sliding 30-trade expectancy drops below `min_expectancy_r`,
immediately transition `promotion_status` to `REVOKED` and block new `LIVE` entries while
permitting `PAPER` shadow recovery.​
  - If rolling or intraday high-water-mark drawdown exceeds `max_daily_drawdown_pct`,
immediately transition `promotion_status` to `HALTED`, trip `circuit_breaker_tripped = 1` in
`daily_risk_snapshots`, block all new entries, and allow ONLY risk-reducing exit orders (`isExit:
true`).​
4. **4ms Sub-Tick Reflex & Swarm SLA:** `NexusFabricRouter`, `fastReflexWorker`, and the
bounded `SwarmThreadPool` (`AGT-001`–`AGT-100`) communicate over zero-copy
`SharedArrayBuffer` (`SAB`) ring buffers with `Atomics` heartbeat counters. End-to-end
swarm inference and `SAB` lag MUST remain `<= 4,000 µs` (`4.0 ms`).​
5. **External Venue API Rules:**​
  - **Solana DEX Quotes:** ALWAYS use Jupiter Swap API v1
(`https://api.jup.ag/swap/v1/quote`) with the `x-api-key` header. NEVER use retired v6 hosts
(`quote-api.jup.ag/v6`).​
  - **Solana Token Safety:** Enforce `RugCheck` verification before any `memecoin` or `spot`
swap dispatch.​
  - **US Equities / ETFs:** Route `stocks_etf` orders through Alpaca Paper/Live API
(`https://paper-api.alpaca.markets` for `PAPER`) using atomic bracket orders (`order_class:
'bracket'`) with deterministic `client_order_id` idempotency.​
  - **Perpetuals / Spot CEX:** Route `futures` and CEX `spot` through Binance and OKX
adapters with isolated margin caps and mandatory stop-loss brackets.​
6. **Treasury Yield Recall Guard:** `TreasurySweepGuard` manages idle capital swept into
yield protocols (e.g., Kamino). Any JIT yield recall must persist `REQUESTED -> CONFIRMED |
ROLLED_BACK | TIMEOUT` in `treasury_yield_recalls` inside `BEGIN IMMEDIATE` SQLite
transactions so process restarts reconcile orphaned recalls cleanly.​
7. **Authentication & Security:** Mutating control endpoints require Privy wallet-possession
cryptographic signature verification (`PrivyAuthGuard`). Never log or commit API secrets.​

function percentile(values: number[], p: number): number | null {​
  if (values.length === 0) return null;​
  const sorted = [...values].sort((a, b) => a - b);​
  const idx = Math.min(sorted.length - 1, Math.ceil((p / 100) * sorted.length) - 1);​
  return sorted[idx];​
}​

async function alpacaFetch<T>(url: string, init: RequestInit = {}): Promise<T> {​
    const res = await fetch(url, {​
     ...init,​
     headers: {​
         'APCA-API-KEY-ID': ALPACA_KEY_ID,​
         'APCA-API-SECRET-KEY': ALPACA_SECRET_KEY,​
         'Content-Type': 'application/json',​
         Accept: 'application/json',​
       ...(init.headers ?? {}),​
     },​
    });​
​
    const rawText = await res.text();​
    if (!res.ok) {​
     throw new Error(`Alpaca HTTP ${res.status} (${url}): ${rawText.slice(0, 400)}`);​
    }​
    return (rawText ? JSON.parse(rawText) : {}) as T;​
}​

 * so Monday 9:30 AM ET opening-range and beta slots are warm before first tick.​

function buildWarmFeatureVector(​
  bars: Array<{ o: number; h: number; l: number; c: number; v: number; vw?: number }>,​
  sessionIsOpen: boolean​
): { vector: Float64Array; midPrice: number; vwapZ: number } {​
    const vec = new Float64Array(FEATURE_VECTOR_LENGTH);​
    const latest = bars[bars.length - 1] ?? { o: 500, h: 501, l: 499, c: 500, v: 100000, vw: 500 };​
    const first = bars[0] ?? latest;​
​
    const midPrice = latest.c;​
    const vwap = latest.vw && latest.vw > 0 ? latest.vw : (latest.h + latest.l + latest.c) / 3;​
    const range = Math.max(0.01, latest.h - latest.l);​
    const vwapZ = Number(((midPrice - vwap) / range).toFixed(4));​
    const sessionRet = first.o > 0 ? (midPrice - first.o) / first.o : 0;​
​
    // Populate core FeatureSlot indices (matching server/src/types/mia5.catalog.ts)​
    vec[0] = midPrice; // FeatureSlot.MID_PRICE​
    vec[1] = midPrice; // FeatureSlot.MICRO_PRICE​
    vec[2] = 0.5; // FeatureSlot.SPREAD_BPS (liquid ETF baseline)​

  vec[22] = sessionRet; // FeatureSlot.RET_1H​
  vec[36] = vwapZ; // FeatureSlot.VWAP_SESSION_DIST_Z​
  vec[56] = Number((range / Math.max(1, midPrice)).toFixed(6)); // FeatureSlot.ATR_14_PCT​
  vec[78] = sessionRet; // FeatureSlot.EQUITY_PREMARKET_GAP_PCT​
